# Карта коду

CLI та переглядач використовують спільне ядро з фіксованим кроком. Стан інтерфейсу й малювання залишаються поза бібліотекою. Публічні імпорти збережено: `rust_playground::simulation::{...}`; внутрішні модулі приватні. Рефакторинг зберіг модель v8. Подальші зміни описані в [сценах playground](playground.uk.md).

## Ядро симуляції

Шляхи в таблицях наведено відносно `src/`.

| Файл | Призначення |
| --- | --- |
| `simulation.rs` | Публічні реекспорти, стан симуляції та доступ до нього для читання |
| `simulation/config.rs`, `simulation/agent.rs`, `simulation/error.rs` | Параметри та перевірки, стан агента, публічні помилки |
| `simulation/spawn.rs` | Створення моделі й початкове розміщення за seed |
| `simulation/groups.rs` | Стабільні ID, напрямлені політики сприйняття, дані груп і колір |
| `simulation/profiles.rs` | Хеш профілю, атомарні зміни та перезапуск за seed |
| `simulation/events.rs` | Журнал змін сцени, команд і станів із номером кроку |
| `simulation/commands.rs` | Команди й переходи між режимами руху |
| `simulation/step.rs` | Атомарний крок: спостереження, розрахунок руху, контакти, запис стану |
| `simulation/boids.rs` | Базовий рух Boids зі сталою швидкістю |
| `simulation/copter.rs` | Вибір швидкості коптера й прогнозне уникнення зіткнень |
| `simulation/dispersion.rs` | Локальне розосередження до заданої дистанції між сусідами |
| `simulation/parking.rs` | Тимчасові локальні цілі для збору й кінцевого паркування маршруту |
| `simulation/actuator.rs` | Межі розгону, гальмування, jerk і швидкості |
| `simulation/geometry.rs` | Повернуті прямокутники/квадрати, точні геометричні запити та обхід |
| `simulation/fields.rs` | Визначення зон вітру й шуму вимірювань |
| `simulation/environment.rs` | Редагування сцени, вітер і відтворювані спостереження |
| `simulation/route.rs` | Геометрія коридору, прогрес, центрування та локальне сповільнення передніх агентів |
| `simulation/collision.rs` | Контакти вздовж руху, хронологічне вибуття й визначення прибуття |
| `simulation/spatial.rs`, `simulation/math.rs` | Просторові комірки та спільні векторні операції |
| `playback.rs` | Відтворення, інтерполяція та обмежене наздоганяння часу |

`Simulation::step` читає єдиний попередній знімок і записує новий стан лише після успішного завершення всіх розрахунків. Контролер, спостереження й контакти розділені; зміни інтерфейсу не повинні переносити розрахунки моделі в переглядач.

## Застосунки

| Файл | Призначення |
| --- | --- |
| `bin/simulation.rs` | Побудова й запуск моделі, файл трасування та повідомлення про помилки |
| `bin/simulation/options.rs` | Довідка, розбір аргументів і перевірки CLI |
| `bin/simulation/output.rs` | Серіалізація знімків у JSON |
| `bin/viewer.rs` | Точка входу вікна й асинхронний цикл кадрів |
| `bin/viewer/mod.rs` | Стан застосунку, ініціалізація та порядок обробки кадру |
| `bin/viewer/input.rs` | Клавіатура, миша, вибір, малювання й розміщення об'єктів |
| `bin/viewer/camera.rs` | Перетворення координат і масштаб |
| `bin/viewer/controls.rs` | Відтворення, поточні команди й перезапуск |
| `bin/viewer/settings.rs` | Параметри моделі, панель властивостей сцени та перевірки |
| `bin/viewer/objects.rs` | Редагування об'єктів сцени, вибір і поворот |
| `bin/viewer/groups.rs` | Вибір, поява й профілі груп, призначення збережених шляхів |
| `bin/viewer/placement.rs` | Етапи ширини/висоти/повороту прямокутника та розміщення полів |
| `bin/viewer/glyphs.rs` | Форма агента та напрямок руху |
| `bin/viewer/canvas.rs` | Сітка, агенти, поля, перешкода, коридори й попередній перегляд |
| `bin/viewer/inspectors.rs` | Дані агентів/об'єктів, повідомлення та нижня панель |
| `bin/viewer/theme.rs` | Налаштування вікна, оформлення й спільні елементи інтерфейсу |
| `bin/viewer/tests.rs` | Перевірки параметрів, координат, масштабу й маркерів |

Кадр оновлює інтерпольовані маркери, обробляє введення, малює поле, обробляє панелі відтворення/параметрів/команд, просуває відтворення й малює інформацію поверх поля. Цей порядок зберігає поточні взаємодії. Замале вікно призупиняє відтворення до обробки кадру.

## Історична перевірка рефакторингу v8

Пройшли всі 73 наявні тести, форматування та Clippy. Одинадцять збережених CLI-сценаріїв дали однакові stdout, stderr і коди завершення; сцена з повернутою перешкодою, вітром, шумом і ламаним коридором зберегла всі 601 кадр JSONL побайтно. Release-вимірювання для 1000 агентів і 20 кроків зберегло відбиток стану `7d6ea305a929cb3d`. Це порівняння в одному локальному числовому середовищі, а не гарантія міжплатформної тотожності чи продуктивності.
